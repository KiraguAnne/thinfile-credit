# Reports

Everything here is regenerated by `make evaluate` (and `make audit`, `make monitor`, `make notebook`), except the report itself.

| File | Contents |
|---|---|
| `REPORT.pdf` | Final report: problem, data, features, technique justification, results, explainability, fairness, architecture, limitations |
| `metrics_table.csv` | Test-set AUC (95% bootstrap CI), Gini, KS, PR-AUC, Brier for every model × feature set × population (all / thin-file / has bureau file) |
| `alt_data_uplift.csv` | Paired-bootstrap AUC differences: A→B, B→C, and the sensitivity sets that split bureau history from external scores |
| `head_to_head.csv` | Behaviour vs bureau history on the same applicants (test applicants with both): AUC with 95% CI and paired-bootstrap differences |
| `confusion_matrix.csv` | Deployed decision rule (decline if PD ≥ threshold): approved/declined × repaid/defaulted, counts and per 1,000, all and thin-file |
| `fairness.csv` | Deployed model by gender, age band and education: AUC, calibration, approval rates, equal-opportunity view |
| `fairness_without_age.csv` | Same audit for the model retrained without age (fairness-through-unawareness check) |
| `leakage_audit.json` | How well bureau-free feature sets predict thin-file status; single-feature proxy flags |
| `shap_by_source.json` | Share of mean \|SHAP\| by data source (application / behavioural / bureau / external) |
| `drift_simulated.csv` | PSI per feature and for the score on a simulated thin-file-heavy batch |
| `metrics.json` | Headline numbers, decision threshold and economics, top SHAP features |
| `figures/` | AUC by feature set, thin-file ROC curves, calibration, confusion matrix, fairness, SHAP summaries |
| `data_dictionary.csv`, `decision_aid_risk_bands.csv` | Written by the walkthrough notebook: column dictionary with missing shares, and the five risk bands with their default rates and actions |
